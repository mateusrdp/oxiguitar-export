# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project
follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

## [0.4.0] - 2026-11-25

### Changed

- **Each format's options are drawn in Slint** (mateusrdp/oxiguitar#346, plugin interface 1.16): `ui/export.slint`, packed in the plugin file, one component that the export dialog shows for the format picked, with OxiGuitar's own widgets, fonts and colours. Same choices as before, still a draft until Export. The plugin needs OxiGuitar 0.23.0 or later (it already did, since its plugin file is an archive); the README and the manual now say so.

## [0.3.0] - 2026-11-25

### Changed

- **The plugin file is a tar archive** (mateusrdp/oxiguitar#347): `build-oxp.sh` packs `manifest.json` first and the library second (`plugin.so`, `plugin.dll` or `plugin.dylib`), as OxiGuitar 0.23 and later read plugin files, which older OxiGuitars can't load. The SDK is at OxiGuitar v0.23.0 (interface 1.16). `scripts/test-all.py` 1.1.0, as in every repository.

### Added

- **Every test with one command** (mateusrdp/oxiguitar#273): `scripts/test-all.py` builds and runs all of this repository's tests, and tests the plugin against the newest OxiGuitar release, with a progress bar, a summary to paste into an issue and a log to diagnose from. The manual has a Features page naming the tests of every feature (CI checks it) and a Testing page.

### Changed

- **CI outlasts a slow Ubuntu mirror**: it installs packages with `scripts/apt-install.sh`, the same file as in every OxiGuitar repository. apt is stopped only when its downloads have not grown for 2 minutes, then tried again on the next mirror; while they grow, it may take as long as it needs (24 Nov 2026: fixed 5-minute tries failed jobs on mirrors at 80 to 185 kB/s).
- **The manual explains the ideas behind the plugin** (its overview, with pictures), shows how to use it with screenshots, says in Architecture and strategy what it can't do yet, what is left out on purpose and where help is wanted, and has a Credits page listing every project it uses, with links and thanks. The README has a plain-words introduction and a Credits section.

## [0.2.0] - 2026-11-19

### Added

- **FLAC, MP3 and Opus** (mateusrdp/oxiguitar#313), beside WAV, in File → Export Audio…'s Format list. FLAC: lossless, 16-bit (with dither) or 24-bit, 44.1 or 48 kHz. MP3: variable bitrate (V0, V2, V4) or constant (128 to 320 kbps), 44.1 or 48 kHz, gapless (an Info/Xing tag). Opus in Ogg (`.opus`): 96 to 256 kbps, always 48 kHz. All pure Rust: rusty_flac, rusty_mp3 and opus-pure, as published.

### Changed

- **Renamed: oxiguitar-wav is now oxiguitar-export** (the repository, the packages `oxiguitar-export` and the Flatpak `io.github.mateusrdp.OxiGuitar.Plugin.export`, the file `export.oxp`, the id `oxiguitar.export`). The manifest replaces `oxiguitar.wav`, so OxiGuitar uses this plugin even when the old one is still installed; remove the old package by hand.
- **Each format's choices are in the export dialog**, under the Format list (plugin interface 1.11): kept with Export…, forgotten with Cancel. The Plugins → WAV Export Settings… entry is gone. The choices are kept per format, so a WAV depth and rate picked before are forgotten once.
- Plugin interface 1.11 (the SDK at OxiGuitar's tag v0.21.2). This version needs that release; older OxiGuitar versions refuse it.

## [0.1.2] - 2026-11-17

### Changed

- **The WAV Export Settings dialog**: the bit depth and the rate are picked in the plugin's own dialog, **Plugins → WAV Export Settings…**, with **OK** and **Cancel**, where OxiGuitar's settings window (Tools → Plugins…, Settings…) used to be: OxiGuitar retired that window (mateusrdp/oxiguitar#306, the core owns nothing of a plugin). A pick is kept only when you press OK. The dialog works with or without a song open.
- Plugin interface 1.9 (from mateusrdp/oxiguitar#306, the SDK at that commit until OxiGuitar's next release is tagged). This version needs that release; older OxiGuitar versions refuse it.

## [0.1.1] - 2026-11-16

### Added

- **Knowledge graph analysis** (Understand Anything): the `.ua/knowledge-graph.json` captures the project's architecture — 18 nodes, 18 edges across 6 layers and a 6-step guided tour — for navigation and documentation. Generated by the `/understand` command.

## [0.1.0] - 2026-11-02

First release in a repository of its own (mateusrdp/oxiguitar#165). The
plugin (`oxiguitar.wav`, file `wav.oxp`) is the one of OxiGuitar 0.11.0, with its
history.

### Added

- `build-oxp.sh`, and a contract test that builds the `.oxp` file and checks
  it through OxiGuitar's plugin host.
- `release.yml`: test builds, and on a `v*` tag a draft release with the
  packages for each system; `publish.yml`.

### Changed

- The plugin SDK is a git dependency on the `v0.11.0` tag of
  mateusrdp/oxiguitar (plugin interface 1.4). The plugin sits at the
  repository's root.
